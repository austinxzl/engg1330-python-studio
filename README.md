# PyStudio · ENGG1330

[Open the practice studio](https://austinxzl.github.io/engg1330-python-studio/)

The practice library contains 101 original exercises spanning Lectures 2–9. Each lecture has ten exercises, including a lecture review problem. There are also twenty mixed exercises and one full-course capstone.

[Open the full-course review](https://austinxzl.github.io/engg1330-python-studio/#review) for the integrated sensor audit and the eight lecture review problems in one place. Each exercise includes an English prompt, a Chinese translation, sample input and output, a hint, a reference solution and executable test cases.

Type a program in the editor. **Run code** uses your custom input. **Submit** runs every test and compares standard output, preserving spacing and internal line breaks. Open a test result to inspect its input, expected output, actual output and any Python error. Tests assess the specified input/output behavior. Review the reference solution when practicing a specific algorithm or implementation technique.

Python runs in a browser worker using Pyodide 0.27.7, downloaded from jsDelivr. Each test has an independent interpreter and temporary files. Drafts, language preference and completion are saved in browser storage on the current device.

This is an independent study resource containing original practice questions.

## Interactive lessons

[Start Lecture 2](https://austinxzl.github.io/engg1330-python-studio/#lesson/L2/1) or [browse the eight chapters](https://austinxzl.github.io/engg1330-python-studio/#learn). Each chapter ends with a checked output prediction and two practice problems.

## Timed mock exams

[Open mock exams](https://austinxzl.github.io/engg1330-python-studio/#exams). Each of the five original English papers follows the December 2022 format of 120 minutes and 100 marks.

- Q1 contains 14 single-line output predictions at 3 marks apiece. Whitespace is ignored.
- Q2 contains four independently marked functions worth 8 marks each.
- Q3 contains one algorithmic programming task worth 26 marks.

Each passing programming case earns 2 marks. Learners can run the visible sample before submission. The timer uses an absolute deadline. When a tab is closed, the next visit seals the saved work at its original deadline and resumes marking. The review shows the score breakdown, predicted and correct output, failing function calls, Python errors, and worked explanations. Retakes are saved separately in browser storage.

## Run locally

Open `index.html` in Chrome, or run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`. The Python runtime requires an internet connection on first use.
